# client

React + Vite front end for the clinic site.

- `src/components/`: page sections (Hero, Services, Gallery, FAQ, Contact) and the AppointmentModal
- `src/components/ui/`: shadcn/ui components
- `src/pages/`, `src/hooks/`, `src/lib/`, `src/types/`: routing, hooks and helpers

Built by the root `npm run build`.
